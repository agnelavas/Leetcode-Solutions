# Binary Search

**Difficulty:** Easy-Medium
**Link:** https://leetcode.com/problems/binary-search/

## Approach
Halved the search interval repeatedly by checking the middle element against the target value in a sorted array.

## Complexity
- **Time Complexity:** O(log n)
- **Space Complexity:** O(1)

## Notes
The solution was tested locally with two test cases and was accepted on LeetCode.
