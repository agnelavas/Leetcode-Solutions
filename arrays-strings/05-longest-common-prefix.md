# Longest Common Prefix

**Difficulty:** Easy-Medium
**Link:** https://leetcode.com/problems/longest-common-prefix/

## Approach
Compared the characters of each string index by index up to the minimum length among all strings until a mismatch was found.

## Complexity
- **Time Complexity:** O(S) where S is the sum of all characters in all strings
- **Space Complexity:** O(1)

## Notes
The solution was tested locally with two test cases and was accepted on LeetCode.
