# Valid Anagram

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/valid-anagram/

## Approach
Used a frequency array of 256 characters. Counted character occurrences in the first string and subtracted counts using the second string.

## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Notes
The solution was tested locally with two test cases and was accepted on LeetCode.
