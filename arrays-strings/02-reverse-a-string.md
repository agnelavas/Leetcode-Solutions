# Reverse a String

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/reverse-string/

## Approach
Used a two-pointer approach where one pointer starts at the beginning and the other at the end, swapping characters until they meet.

## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Notes
In-place character swapping eliminates the need for auxiliary memory.
