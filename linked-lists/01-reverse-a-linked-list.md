# Reverse a Linked List

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/reverse-linked-list/

## Approach
Reversed the links iteratively using three pointers (prev, curr, and next) in a single traversal.

## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Notes
The solution was tested locally with two test cases and was accepted on LeetCode.
