# Valid Parentheses

**Difficulty:** Easy-Medium
**Link:** https://leetcode.com/problems/valid-parentheses/

## Approach
Used a stack data structure to push opening brackets and pop them when matching closing brackets are encountered.

## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

## Notes
The solution was tested locally with two test cases and was accepted on LeetCode.
